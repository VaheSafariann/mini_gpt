# MiniGPT — Custom Small Language Model from Scratch

A decoder-only Transformer (GPT-style) built from scratch in PyTorch, trained on the TinyStories dataset.  
This is a learning project — every line of code written and understood manually.

---

## Architecture

| Parameter        | Value  |
|-----------------|--------|
| Model type      | Decoder-only Transformer |
| Layers          | 4      |
| Attention heads | 4      |
| Embedding dim   | 128    |
| Context length  | 256    |
| Vocab size      | 8192   |
| Parameters      | ~10M   |

---

## Dataset

[TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories) — a dataset of short children's stories generated by GPT-3/4.  
Used 200,000 stories for training.

---

## Project Structure

```
mini_gpt/
├── configs/
│   └── config.py          # all hyperparameters in one place
├── data/
│   ├── dataset.py         # Dataset class — tokenizes and slices into context windows
│   ├── train_tokenizer.py # trains BPE tokenizer on TinyStories
│   └── tokenizer/         # saved vocab.json + merges.txt
├── src/
│   ├── attention.py       # Multi-Head Causal Self-Attention
│   ├── block.py           # TransformerBlock (Attention + FFN + LayerNorm)
│   └── model.py           # MiniGPT — full model assembly
├── checkpoints/           # saved model checkpoints
├── train.py               # training loop
├── generate.py            # text generation / inference
└── README.md
```

## Setup

```bash
git clone https://github.com/VaheSafarian/mini_gpt.git
cd mini_gpt

python -m venv .venv
.venv\Scripts\activate        # Windows
pip install torch tokenizers datasets transformers
```

---

## Train Tokenizer

```bash
python mini_gpt/data/train_tokenizer.py
```

Trains a BPE tokenizer on TinyStories and saves `vocab.json` + `merges.txt` to `data/tokenizer/`.

---

## Train Model

```bash
python mini_gpt/train.py
```

Trains for `max_steps` steps, logs loss and perplexity every `eval_interval` steps, saves checkpoints.

---

## Generate Text

```bash
python mini_gpt/generate.py
```

Example output after 5000 steps on 200k stories:

```
Note: the generator`s performance is limited due to resource constraints. The model

```
